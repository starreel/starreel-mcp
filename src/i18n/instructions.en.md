StarReel = prepaid AI short-drama production pipeline (script → AI rewrite → assets → storyboards → shot frames → video → audio → final cut .mp4), 120+ tools, all via this server.

★The first step is always to determine “what materials the client already has” — this decides the entry point; choosing the wrong entry causes real paid rework (full table and key points: get_capabilities_guide):
· Novel / story outline / synopsis (not yet in script form) → create_drama → set_script → rewrite_script → review_script
· Already-written script (with scene headings + dialogue-line structure) → set_script → rewrite_script → get_script → review_script
· Wants to use another AI platform to rewrite / says “your AI changed too much” → get_script_format_spec → rewrite on external platform → check_script_format(errors cleared) → Exit A adopt_external_script(with annotations · direct adoption · free) or Exit B set_script + rewrite_script(story layer only · platform adds annotations)
· Completed final storyboard table (per-shot duration / shot size / camera movement; common for samples, TV stations, or brands) → get_storyboard_table_spec → organize with external tool using template → check_storyboard_table(errors cleared) → import_storyboard_table(default auto_complete) → get_autofill_status until done → review_storyboards
· Structured data (client’s own tool / spreadsheet export / third-party AI outputs JSON directly; wants to build this episode’s storyboards in one pass; characters/scenes/props still extracted by extract_assets) → get_bulk_import_spec → check_bulk_import(errors cleared) → bulk_import_storyboards(default auto_complete) → get_autofill_status until done → review_storyboards
· Own character sheets / scene images / prop images / shot frames (client real assets) → upload_image · set_character_portrait · upload_scene_image · upload_prop_sheet · upload_shot_frame(client-owned assets only; to alter the image use generate_shot_frame) · upload_shot_footage(full live-action/screen-recording clip as one shot’s final video)
· Own voice sample / specified voice → clone_voice → speak_with_voice(test listen) → set_character_voice(original-voice drama: before generate_videos) / assign_voices
· No external audio source, wants to use a voice already spoken by a character in the video as baseline → generate_videos(first generate one shot for each speaking character) → set_voice_anchor_from_shot → generate_videos(remaining shots) → get_pipeline_status check stale_shots
· Song + lyrics (MV) → create_drama → set_mv_lyrics → generate_mv_story → generate_mv_script → get_mv
· Lyrics only, no song (wants MV) → set_mv_lyrics → suggest_mv_song_styles → quote_mv_song(user agrees) → generate_mv_song → get_mv_song(test listen) → select_mv_song → generate_mv_story → generate_mv_script
· Product / brand (ad, brand microfilm) → create_drama → add_product → generate_product_sheet → list_products → render_multi_aspect
· Generated shots / final cut need changes (change lines, trim, split shot, regenerate a shot, switch engine) → scan_dialogue_coverage / scan_intra_shot_cuts diagnose first → update_shot / replace_shot_dialogue / repair_episode_dialogue / split_shot / trim_shot / regenerate_shot_video / edit_video_shot → rerender_episode
· Existing video segment (own asset or generated shot), wants to keep action but replace character / outfit overall (video repaint) → get_repaint_capabilities → upload_shot_footage(own video) → quote_repaint_shot_video / quote_reskin_shot_video → repaint_shot_video / reskin_shot_video → get_repaint_status
· Wants to edit themselves: needs per-shot asset pack (raw video / dialogue tracks / SFX / music / subtitles) → export_handoff_pack → get_handoff_toolchain → save_handoff_toolchain
· Multilingual distribution → translate_subtitles → update_project_settings

Pipeline order (do not skip steps): create_drama(create drama and set setting_brief/aspect ratio/video_engine/image_model/consistency anchors, all free) → set_script → rewrite_script → ★review_script → extract_assets → quote/generate_storyboards → ★review_storyboards → character sheets + turnarounds (generate_character_sheets) / scene images / prop images / color script → ★review_assets → run_precheck → quote/generate_frames(default only first frame) → tail_frame_plan(which shots need independent last frames) → quote/generate_frames(last_frame) → chain_frames (dry_run first, run it after confirmation) → get_jobs (wait for its reframe image jobs to finish) → ★review_frames → quote/generate_videos → audio → ★review_videos → compose_episode → get_final_cut → review_final_cut. Use get_pipeline_status to check progress.
Five free hard gates (skip → 400): review_script(before extract_assets/storyboards) · review_storyboards(before frame generation via generate_frames, including single-shot generate_shot_frame) · review_assets(after character/scene/prop images are generated, before frame generation via generate_frames / generate_shot_frame; pass its token as asset_review_token) · review_frames(before video generation, including single-shot regenerate_shot_video) · review_videos(before compose_episode); pass review_token to downstream paid tools (both batch and single-shot tools require it); report findings to the client verbatim item by item.
★After each review layer you must also personally QC: inspect assets item by item according to returned agent_qc, then submit_qc_report; gray-release dramas cannot proceed without the report.
Billing discipline: prepaid, no overdraft; for large steps quote_* → tell client estimated_points exactly as returned → after client agrees, generate_*(quote_id); never confirm on your own; image-generation quotes provide estimated_points(upper bound, prepare balance by this) and typical_points(usual spend), state both; text steps are postpaid by token; on 402 stop and ask client to recharge, do not retry.
Long tasks are async: generate_* returns immediately; poll with get_pipeline_status / get_storyboards / get_run_status; image pending = still generating, do not call again (duplicates charge credits).
After rewrite succeeds, only use edit_rewritten_script for targeted edits; do not rerun rewrite_script; the single source of truth for character appearance is the character profile (update_character), do not write it into visual_lock/art_bible.
Choosing image model/video engine, or client asks “which model is better / how to save more” → get_capabilities_guide(section=model_guide): measured pros/cons, prices, decision steps, and recommended combos for each model; proactively explain and decide with client when creating the drama.
For action / fight / skill demo videos → get_capabilities_guide(section=action_film): storyboard-table fast path, first frame frozen at wind-up pose, grouping and rhythm trimming.
If unsure which tool to use, or client asks “what can you do” → call get_capabilities_guide first (free, local, no internet).
