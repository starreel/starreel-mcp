StarReel = a prepaid AI short-drama production line (script → AI rewrite → assets → storyboards → shot frames → video → audio → final cut .mp4), 120+ tools, all served by this server.

★ Step one is ALWAYS to judge "what material does the customer have" — it decides the entry point, and rework from a wrong entry costs real credits (full table and key points: get_capabilities_guide):
· A novel / story outline / synopsis (not yet in script form) → create_drama → set_script → rewrite_script → review_script
· A finished script (scene headings + dialogue lines) → set_script → rewrite_script → get_script → review_script
· They want to rewrite on another AI platform themselves / complain "your AI changes too much" → get_script_format_spec → let the external platform rewrite → check_script_format (errors down to zero) → exit A: adopt_external_script (with annotations · adopted as-is · free) or exit B: set_script + rewrite_script (story layer only · platform adds annotations)
· A finished storyboard table (seconds / shot size / camera move per shot; typical for pilots or sheets handed to TV stations and brands) → get_storyboard_table_spec → tidy it with an external tool against the template → check_storyboard_table (errors down to zero) → import_storyboard_table (auto_complete by default) → get_autofill_status until done → review_storyboards
· Structured data (customer's own tools / spreadsheet export / third-party AI emitting JSON, to build the episode's storyboards in one go; characters / scenes / props are still extracted by extract_assets) → get_bulk_import_spec → check_bulk_import (errors down to zero) → bulk_import_storyboards (auto_complete by default) → get_autofill_status until done → review_storyboards
· Their own character sheets / scene plates / prop sheets / shot frames (the customer's real material) → upload_image · set_character_portrait · upload_scene_image · upload_prop_sheet · upload_shot_frame (customer-owned material only; to change the picture use generate_shot_frame) · upload_shot_footage (a whole live-action / screen-recorded clip as a shot's final footage)
· Their own voice sample / a specific voice → clone_voice → speak_with_voice (preview) → set_character_voice (native-voice dramas: before generate_videos) / assign_voices
· No external voice source; they want a voice a character already spoke in the film as the reference → generate_videos (one shot per speaking character first) → set_voice_anchor_from_shot → generate_videos (the remaining shots) → get_pipeline_status and check stale_shots
· A song + lyrics (MV) → create_drama → set_mv_lyrics → generate_mv_story → generate_mv_script → get_mv
· Lyrics only, no song (they want an MV) → set_mv_lyrics → suggest_mv_song_styles → quote_mv_song (customer agrees) → generate_mv_song → get_mv_song (preview) → select_mv_song → generate_mv_story → generate_mv_script
· A product / brand (ads, brand films) → create_drama → add_product → generate_product_sheet → list_products → render_multi_aspect
· Generated shots / a final cut need changes (dialogue, trimming, splitting, regenerating a shot, switching engines) → scan_dialogue_coverage / scan_intra_shot_cuts to diagnose first → update_shot / replace_shot_dialogue / repair_episode_dialogue / split_shot / trim_shot / regenerate_shot_video / edit_video_shot → rerender_episode
· An existing video (own footage or a generated shot) where they want to keep the motion but replace the character / wardrobe entirely (video repaint) → get_repaint_capabilities → upload_shot_footage (own video) → quote_repaint_shot_video / quote_reskin_shot_video → repaint_shot_video / reskin_shot_video → get_repaint_status
· They want to edit themselves and need a per-shot handoff pack (clean footage / dialogue track / SFX / music / subtitles) → export_handoff_pack → get_handoff_toolchain → save_handoff_toolchain
· Multilingual release → translate_subtitles → update_project_settings

Pipeline order (no skipping): create_drama (set setting_brief / aspect ratio / video_engine / image_model / consistency anchors at creation — all free) → set_script → rewrite_script → ★review_script → extract_assets → quote/generate_storyboards → ★review_storyboards → character sheets + design sheets / scene plates / prop sheets / color script → ★review_assets → run_precheck → quote/generate_frames (first frames only by default) → tail_frame_plan (free · which shots need a separate last frame) → quote/generate_frames (frame_type=last_frame) → chain_frames (seams · dry_run:true first to see the plan, run it after the customer confirms) → get_jobs (wait until its reframe image jobs finish; failed ones show error_msg) → ★review_frames → quote/generate_videos → audio → ★review_videos → compose_episode → get_final_cut → review_final_cut. Track progress with get_pipeline_status.
Five free hard gates (skipping → 400): review_script (before extract_assets / storyboards) · review_storyboards (before frames, incl. per-shot generate_shot_frame) · review_assets (before frames; pass its token as asset_review_token) · review_frames (before videos, incl. per-shot regenerate_shot_video) · review_videos (before compose_episode); pass the review_token to downstream paid tools (batch and per-shot alike) and relay every finding to the customer verbatim.
★After every review you must also do your own QC: open each item in the returned agent_qc materials yourself, answer its checklist, and submit_qc_report; on gated dramas the token is unusable until the report is in.
Billing discipline: prepaid, no overdraft; for large steps call quote_* → tell the customer estimated_points as-is → only after they agree call generate_* (quote_id), never confirm on their behalf; image quotes give estimated_points (upper bound — prepare balance for it) and typical_points (usual spend) — say both; text steps are billed post-hoc by tokens; on 402 stop and let the customer top up, do not retry.
Long tasks are async: generate_* returns immediately; poll with get_pipeline_status / get_storyboards / get_run_status; an image in pending is still generating — do not call again (double billing).
After a successful rewrite only spot-edit with edit_rewritten_script, do not rerun rewrite_script; the single source of truth for character appearance is the character profile (update_character) — never put it into visual_lock / art_bible.
Choosing an image model / video engine, or the customer asks "which model is better / how to save" → get_capabilities_guide (section=model_guide): measured strengths and weaknesses, prices, decision steps and recommended combos; bring it up proactively when creating the drama.
Action / fight / skill-showcase films → get_capabilities_guide (section=action_film): the storyboard-table fast path, first frame frozen on the wind-up, grouping and rhythm cutting.
Unsure which tool to use, or the customer asks "what can you do" → call get_capabilities_guide first (free, local, no network).
