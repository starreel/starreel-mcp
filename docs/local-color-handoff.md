# 本地后期交接验收

## 范围

扩展 MCP `export_handoff_pack`：`purpose=local_color` 导出本地调色交接包；
`media_type=images` 只读导出现有首尾帧，无需视频。默认调用保持原视频剪辑包行为。
平台 API、数据库、生成优先级和收费流程不变；本次未部署或发布 npm。

## 验收标准

- 正例：现有图片无视频也能导出；视频调色包保留声音、裁剪和字幕信息。
- 负例：鉴权失败不能降级绕过；无图片不能自动生成；下载失败不能标完成；非空目录不能覆盖。
- 回归：默认剪辑包保留 LUT，现有 fetch/compile/assemble 流程继续可用。
- 交付：源素材字节不变；带原始清单、SHA-256、后期说明和本地对比页；不自动上传/收费/回填。

## 验证记录

- 改动前工具测试 3 项失败，暴露图片出口缺失和调色包仍携带自动 LUT；2 项旧行为通过。
- 下载端到端基线失败：图片清单没有可下载资源。
- 改动后 `npm run build && npm test`：7 项通过，包括 MCP handler 到本机 HTTP 下载、文件和清单落盘。
- `node scripts/release-check.mjs --ci` 通过；OpenAPI 已重新生成。
- `bash huobao-drama/docs/handoff/selftest.sh`：13 项通过，包含真实 FFmpeg 装配和 LUT 回归。
- 使用实时只读分镜结果，通过本地新 handler 与下载脚本取回现有测试图片，SHA-256 与此前原件一致。
  此项证明本地新代码适配实际数据，不代表线上 MCP 已更新。
- 浏览器实看未完成：工具安全策略不允许打开 file://。未绕过；文本转义和产物存在性由测试覆盖。

## 发布前

合入 main 后按 MCP 发布流程发布；单个授权项目验证图片与视频交接，确认客户端拿到新参数和工具链。
不需要部署生成后端或广州 worker。本地后期仍需客户选择工具、确认参考样张、检查结果；
下载成功不是后期完成，比较页不自动验收。外部上传素材的历史调色状态标 unknown，不保证可逆。
